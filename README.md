# לרז שלי

אתר מתנה אישי לרז — עמוד יחיד בעברית (RTL), נבנה ב-HTML/CSS/JS פשוט ומתארח ב-GitHub Pages.

**כתובת האתר החי:** https://ariel242.github.io/raz-site/

## מבנה הפרויקט

```
index.html   — כל תוכן העמוד, מחולק לסקשנים
styles.css   — עיצוב (פלטת קרם/זהב, RTL, רספונסיביות, אנימציות)
script.js    — אנימציות גלילה וקרוסלות תמונות
assets/      — התמונות שנבחרו, ממוינות לפי סקשן
```

## עריכת תוכן

כל הטקסטים שעדיין צריך למלא מסומנים בסוגריים מרובעים, למשל:

```
[כאן ייכנס משפט פתיחה אישי וחם]
```

פשוט לפתוח את `index.html`, לחפש `[` ולהחליף בטקסט הסופי.

## פריסה

כל שינוי שנדחף ל-branch `master` מתפרסם אוטומטית באתר החי תוך דקה-שתיים:

```
git add -A
git commit -m "עדכון טקסטים"
git push
```
